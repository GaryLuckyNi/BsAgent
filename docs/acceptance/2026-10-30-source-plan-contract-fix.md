# 多来源计划协议修复验收

对应 trace：`cee9079511ef1eeffad72ca8615493ff`。

## 根因与修复

原模型两次选择同一 Tushare 来源的现金流量表和财务指标工具，违反每源单选；整组计划在执行前被拒绝，零 MCP 调用。旧修正提示未指出具体冲突，最终生成失败又没有保存失败队列，导致合成层允许重规划，将本地格式失败误当成取证路径失败。

改为一个内部计划函数，每个可信来源仅有一个可为空的选择位置，首次生成全部入选参数及相关性顺序。候选跨源、重复或遗漏排序、同源多选、未知字段由宿主拒绝，不静默丢弃候选。结构错误反馈具体错误码、可信来源与候选身份，仅在当前任务修正一次；最终失败保存 failed 队列和 `source_plan_invalid`，既有门控阻止重规划。两次生成错误或成功修正前的错误均保存在 `generation_errors`。

实际执行仍逐个生成原生请求与回执。单来源参数错误依旧在该来源执行前本地校验或执行后修正，未执行备用请求不写入工具对话。固定 Skill、写操作、审批、共享搜索预算与副作用保护保留。
