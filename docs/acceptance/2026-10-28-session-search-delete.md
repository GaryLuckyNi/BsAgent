# 研究记录搜索与删除验收

## 结果

研究列表接入服务端关键词查询，按当前账号与租户检索未删除消息的历史正文，包含标题及摘要来源；关键词按字面匹配，250ms 防抖，忽略过期请求。过滤列表保留当前会话与头部内容。

操作菜单与确认框采用用户选定的珊瑚红方案。只有确认后发起删除；取消、关闭和 Escape 不删除。删除中禁止重复操作和关闭，失败保留弹窗并支持重试。删除当前会话切换到剩余记录，无记录则进入新草稿；删除其他会话保留当前选择。

服务端采用会话状态删除，屏蔽列表、历史消息、旧请求重放、新提问与运行事件访问，保留执行审计。可停止的持久任务先请求停止；不支持安全停止的旧执行返回明确错误并保留会话。并发新任务使用会话状态及序列号 CAS，避免删除后继续创建任务。
