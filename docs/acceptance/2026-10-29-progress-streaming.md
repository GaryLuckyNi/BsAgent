# 完整文本与实时进展验收

## 问题与处理

研究目标和计划的公开投影曾共用 200 字短标签限制，保存时还分别存在 500 字和 3000 字限制。现在目标和每条任务保留完整清洗后的文本，实时展示与会话保存保持一致。活动短标签仍保留原有长度限制。历史中已经截断的文本不自动回填。

研究进展原来等待节点结束才更新。现在复用 Router 和 Planner 的真实流式调用，只投影公开的目标和任务字段，在生成过程中以同一事件 ID 更新；完整校验结果覆盖草稿，失败则覆盖为失败状态。草稿不进入执行调度，不展示控制 JSON 或原始 reasoning，不增加总结调用或开启 thinking。

回答原来等待完整段落，存在已知数值时还会等待完整输出。现在按完整句子或行发送，链接、网址、代码保持完整；每次发送前累计检查禁止建议和已知数值，最终全文校验继续保留。已发布正文后的调用错误不透明重放整个合成节点，避免多次尝试拼接；未发布正文的可恢复错误仍可重试。

原生流式调用的观测测试同时覆盖原生 HTTP 与 ChatOpenAI 路径，确认模型调用次数、父节点和 token 用量不变。观测副本复用嵌套 JSON 脱敏；转换失败仅省略观测正文，保留模型及用量，不回退到原始输入。
