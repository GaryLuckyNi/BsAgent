# 回答文章引用跳转验收

## 行为

新回答中已知的 `source_1` 等来源编号转换为可点击的数字引用，点击后在新标签页打开 web_search 返回的文章 URL。来源表按 URL 去重，同一来源重复引用复用编号。新回答的 Markdown 链接随正文保存，重新打开消息后仍能点击。

例如原 trace 的 `（source_2）` 转换为 `（[2](<https://www.cnstock.com/commonDetail/815148>)）`。来源引用转换不增加模型调用、thinking 或工具请求。
