# 空返回继续备用来源验收

对应 trace：`f408af62e5f5581cf76c353618796754`。

## 根因

本轮补取立昂微 2023Q4 营收，生成的来源顺序为 `mcp.tushare.express`、`web_search`。前者原始回执为 `status=success`、`execution_state=completed`、`result=[]`、`error=null`。旧队列仅判断执行状态就宣布来源成功，提前剪枝联网搜索，因此最终没有继续补取同比需要的基期数据。

## 修改

仅在普通只读备用队列增加明确空返回的分支。空数组、空对象、null 与空白文本记录为 `tool_result_empty`，继续已规划的下一来源。自有联网搜索依据明确契约判断摘要与来源列表是否同时为空。来源未用尽时移除单次执行器的暂时成功任务结果，保持当前任务待执行及来源切换进展；所有来源用尽时返回“未取得数据”的业务失败。

不改写原始回执，不把空返回伪装成提供方执行错误，不触发同工具参数修正。保留每源单选、搜索末位、审批、目录快照、Skill 和副作用门控。`0`、`false`、包含零值的记录均有效；未知第三方包装对象不猜测内容字段，也不执行覆盖性自验。

## 验证

新增回归在旧实现中有 8 项失败，均表现为空返回后未切换或过早完成；修复后队列单测 25 项通过。最终 14 个相关测试文件共 **346 项通过，耗时 6.43 秒**，Ruff 与 `git diff --check` 通过。

验证包括：明确空返回后切换下一专业来源；专业来源均空后执行预生成搜索；所有来源都为空时停止且不宣称取数成功；零值与 false 不误判；切换期间不发布失败终态；原始成功回执保持成功；真实 StateGraph、BM25、工具网关与独立 SQLite 回执下完成备用切换，且不增加模型调用、不请求重规划。

本次读取原 trace 核对真实返回，回归使用受控来源，没有重新请求该公司的真实财务数据或联网搜索。代码保留于 `codex/public-mcp-documentation`，未提交、未合并。
