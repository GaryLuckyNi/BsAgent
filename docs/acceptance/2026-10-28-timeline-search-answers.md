# 研究进展与搜索摘要验收

## 行为

根据后续界面反馈，隐藏“查看任务明细”和网页活动的“查看搜索范围”及其展开内容，避免与研究计划重复。搜索状态、网页数量和搜索摘要继续展示。进度折叠标题改为“研究进展”。目标、计划、工具状态沿用现有 SSE 到达即更新，不新增思考输出。

Search API 仅保留供应商已返回的可选字符串 answer，不修改请求协议、不额外请求模型。成功搜索的非空摘要经过既有脱敏后随完成事件传递，在 timeline 下方显示；无 answer 时没有摘要区，不根据 snippet 补写。进度摘要最多 4000 字符，原工具结果仍遵循原有结果预算。

并行结果按 task_id 各自保存，第一项搜索完成即可显示，后续任务不会覆盖其他任务的摘要。未预选工具的任务按实际 ToolResult 分类，清除原通用取证分组里的进行中项。实时 SSE、AG-UI、会话 metadata 与历史恢复使用同一 answer 字段。

## 恢复路径与审查

独立审查发现批次权限恢复未发布工具事件，恢复 API 也未消费 custom 流，已补通逐项开始/完成、摘要透传、正文增量及历史合并。恢复调用保持原有身份、授权与快照校验，不重新申请或扩大权限。

第二轮审查发现读取终态时固定 checkpoint_id 会返回旧快照，已在终态读取时仅移除该定位字段，保留 thread_id 和命名空间。真实 LangGraph 覆盖固定/非固定检查点与完成/再次中断的四种组合。修复经审查复核通过。
