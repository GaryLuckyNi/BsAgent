# 正文排版与引用预览验收

## 已实施范围

- 正式回答正文采用 16px 与 1.9 行距；加粗使用 700 字重与更深文字色，标题调整层次。Streamdown 的加粗实际为 `span[data-streamdown="strong"]`，样式同时覆盖该结构与原生 `strong`。
- 数字引用使用小型编号徽标。悬停 200ms 打开预览；移至预览卡可继续阅读，离开延迟关闭；键盘可进入卡片并以 Esc 关闭、返回原引用。触屏点击可先查看预览。
- 预览复用实际取证来源的标题、摘要、日期、URL。站点 icon 由浏览器读取对应 origin 的 `/favicon.ico`，不发送 referrer，失败时显示通用网页图标。
- 新的 `answer_sources` 公开事件先于正文发出，Agent Protocol 与 AG-UI 均透传；最终响应与普通、审批恢复路径的消息元数据保留来源。前端实时接收与历史恢复使用同一解析器。
- 来源编号不重排，来源匹配同时核对编号与 URL，防止把其他资料展示为当前引用。非法 URL 与不匹配编号不进入预览元数据。
- 不新增模型或搜索调用。模型原文的 emoji/icon 与颜色保持原样，不要求每个标题带 icon。
- 历史消息缺少元数据时，仅展示真实域名、地址与“暂无摘要”；不生成虚假文章标题、日期或摘要。
