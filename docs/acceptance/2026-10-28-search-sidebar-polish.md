# 搜索与侧栏细节修复

## 已完成的正式页面修改

1. 定位底色采用搜索选中项的灰蓝 `#f1f4f7`，保持 1.8 秒后用 0.8 秒淡出。2.6 秒后移除临时层和高亮类；相同消息再次定位重新播放，不重建消息内容。减少动态效果偏好下保留短暂底色后直接移除。
2. 搜索结果只由当前选中状态控制底色，移除独立 `:hover` 底色，避免鼠标停在旧条目时与键盘选择同时高亮。
3. 会话列表右侧增加 8px padding，保留 6px 细滚动条。
4. 移除侧栏长搜索按钮，改为工具条右侧搜索图标按钮，保留可访问名称及悬停标题。
5. 移除页面顶栏右上角无实际功能的全局搜索按钮。

## 验证

- `npm --prefix frontend test`：20 个文件、133 项通过。
- `npm --prefix frontend run build`：通过，保留既有依赖注释、分包提醒。
- `git diff --check`：通过。
- 浏览器方向键选择后，只有第 2 项背景色为 rgb(241,244,247)，其余透明。
- 点击搜索结果后，真实定位底色为 rgb(241,244,247)，动画时长 2.6s；之后临时层及高亮类均已移除。
- 浏览器读取列表 padding-right 为 8px，顶栏全局搜索元素不存在。
