# 停用独立分析执行验收

## 结果

- 保留 `backend/app/graph/nodes/analysis_agent.py` 的实现及其单独测试，保留历史计划与分析交接契约。
- 当前运行图不注册 `analysis_agent`，普通任务和固定 Skill 步骤均无法再调度该节点。
- Planner 初始规划与修订只接受新的 tool/Skill 任务。提示词明确：已有证据上的解释、比较、推演、归因和最终判断由合成层完成，不得改写为额外工具任务。
- 旧计划内停用的分析步骤不自动计为数据缺失；独立工具继续执行，真实依赖不被绕过。必要补证不再被旧分析任务阻挡。
- 固定 Skill 的未执行无工具分析步骤明确结算为 `analysis_agent_disabled`，停止该工作流，不伪造完成或转换成工具调用。

最终相关回归：306 passed，覆盖 Planner、调度、合成、上下文、历史结果、节点实现、候选检索、可观测性、动态图和能力恢复。健康检查因沙箱内 PostgreSQL 连接等待单独执行，放开本机连接后 17 passed。修改文件的 Ruff 与 `git diff --check` 均通过。
