# 研究页整页字号协调验收

## 调整

普通正文扩大至 16px 后，周边仍有大量 10–13px 文字，导致阅读区与操作区比例失衡。本轮仅调整 CSS 字号、行高、间距与少量辅助文字颜色，复用原有深蓝、暖金和灰白体系。

| 用途 | 字号 |
| --- | --- |
| 侧栏摘要、时间、消息状态、输入提示 | 12px |
| 导航、侧栏标题、按钮、作者、研究进展、表格 | 14px |
| 用户提问、助手正文、输入文字 | 16px |
| 回答各级标题、来源抽屉标题 | 20px |
| 页面标题 | 桌面 24px，窄屏 20px |

字级通过 `--research-text-*` 变量集中维护；编号引用等紧凑标记仍使用独立字号。正文行高 1.8，标题段前／段后 1.4em／0.6em，侧栏条目内容最小高度 72px。

## 验证

- 使用正式 `/ai-research` 页面和真实历史消息检查，未发送研究请求或修改会话内容。
- 1280×720：侧栏标题计算字号 14px、摘要／时间 12px、页面标题 24px、正文 16px、回答标题 20px、输入 16px、表格 14px；条目内容高度 72px，无页面横向溢出。
- 390×844：页面标题 20px，输入 16px，输入区宽 360px，无页面横向溢出。测试后清除临时视口覆盖。
- `npm run build` 通过。仍有原有的第三方 PURE 注释、循环 chunk 和大 chunk 提醒。
- `git diff --check` 通过。纯视觉调整未新增实现镜像单测。
