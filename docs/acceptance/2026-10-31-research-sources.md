# 本轮网页来源总览验收

用户已确认 `2026-10-31-research-sources-design.md`，本次已接入正式回答组件。继续当前相关 feature 分支，未提交、推送或合并工作区内其他改动。

## 实际行为

- 助手正文完成流式输出后，才在回答尾部、复制与反馈之前展示“研究来源”入口，网页和网站计数均来自真实来源。生成中、没有正文或零网页时隐藏；来源元数据仍可提前接收，供正文中的引用预览使用。
- 桌面端右侧抽屉宽 445px；700px 以下使用底部面板。头部、筛选和底部说明固定，列表独立滚动，支持安全区和减少动态效果。
- 支持全部网页／正文引用筛选，以及按标题、摘要、网站进行本地搜索；没有匹配结果时提示继续修改关键词。
- 展示实际标题、摘要、域名、已知日期、原始编号与 favicon。缺失内容不补造；favicon 失败回退通用图标。
- 关闭按钮、遮罩、Esc 均可关闭；Radix Dialog 管理焦点和背景滚动，关闭回到入口并保留阅读位置。打开时清空旧过滤条件。
- 来源标题以新标签页打开，附 `noopener noreferrer`。正文引用继续使用已有预览卡片与原文跳转规则。

## 数据范围

后端 `collect_search_sources` 从当前 request 独立 checkpoint 的工具回执收集成功的内置搜索结果，因此包含重规划前成功返回但最终未引用的网页；不会加入未执行的备用调用、失败调用、其他数据接口返回值、后台文档补全搜索或其他轮次的网页。

合成层的模型 payload 与引用映射继续使用原证据投影；额外网页只用于公开目录，不把未采用的材料重新注入模型。既有来源编号不变，额外网页分配新编号；按调用回执与各结果的顺序公开。

复用 `answer_sources`、最终响应与消息元数据，无新数据库迁移。最终响应也执行收集，覆盖无模型和提前结束分支。审批恢复与历史读取复用同一持久化通路。

前端按规范 URL 去重（忽略片段、规范默认端口），保留编号别名。采用 Markdown AST 关联数字引用的编号与地址，不将代码示例、图片、普通文字链接或编号错配视为引用。仅在面板打开时解析正文引用，避免随流式片段反复解析全文。

新完成的回答支持本轮完整目录。早期未保存完整来源元数据的历史回答只能展示原先已保存的资料，不伪造“全部搜索网页”。
