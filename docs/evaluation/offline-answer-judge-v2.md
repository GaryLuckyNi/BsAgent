3. reasoning_correctness：公式、期间、单位、正负号、逻辑与因果边界是否正确。允许等价公式，不要求字面公式匹配。区分成本占比和收入占比、单季与累计、相关与因果、计划与实施、会计口径和市场价格。舍入近似合理时不误判；明显算术错误、无依据的必然性或逻辑跳跃应指出。
