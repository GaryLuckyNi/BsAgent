# 当前合成提示词固定输入回放结果

## 结论与行动重点

26 条完整输入已回放：23 条产出回答、3 条申请补证，无调用或协议失败；23 条回答中 22 条评审有效、1 条评审因引文无法逐字定位而拒收。**本轮不足以宣称质量整体提升：一些旧错误不再出现，但边界转等式、期间运算、加总和字段语义错误仍可复现，而且评审器仍会漏检。**

当前优先事项应收敛到两类：

1. **推导必须保持输入、公式、输出及边界一致。** 不等式不能变等式，九个月减六个月不能解释第二季度，列表总数须与实际行一致，前收盘不能写成当日收盘。
2. **证据身份和交付门槛不能被旧判断替换。** 历史助手摘要可以提供有用线索，但其中的推断不能直接升级为当前已核事实；开放式分析不应把入口扩展的所有研究项自动变成缺一不可的条件。

本轮未修改生产提示词或业务链路。下一轮宜先做仅含通用推演约束的离线候选，与当前版本在相同输入、相同模型下成对运行；确认减少错误且不增加无必要补证，再决定上线。暂不增加独立 Analysis Agent，不把所有第三方数据改为强制交叉验证，也不为单家公司或年份编写提示词特例。

## 实验边界

版本：`synthesis-fixed-input-2026-11-01-v1`。输入来自已建真实集的完整合成输入，调优集 25 条、保留集 1 条。只替换为当前合成提示词，保留原始 user_prompt 中的材料、目标、历史上下文、预算状态和输出 schema；不注入评测标准，也不额外把封存的最终答案放进生成端。原输入本身包含的历史摘要仍保留，以观察其真实影响。

当前提示词从 `_render_answer` 源码提取，包含按需核验、业务表达、来源引用和决策协议的实际条件追加内容；使用当前配置 `deepseek-v4-flash`，temperature=0.2、thinking=false，输出上限取当前源码，本批均为 16384。没有思考模式，也没有新的工具调用。26 次生成均首轮协议有效，没有发生格式修复。

历史记录和本次 API 响应多使用名称 `deepseek-flash`，本次请求配置为 `deepseek-v4-flash`；请求名与响应名不同不能证明底座模型变化。此前据名称差异作出的模型变化推断证据不足，已在后续对照中分别保存两者。历史记录仍跨多个提示词版本且有采样波动，不能将新旧答案差异归因于提示词单一变量。本轮为固定输入的模型合成回放，不重建上游状态、数值投影、完整节点门控、重规划执行或 UI 流式渲染，因而不代表端到端生产效果。历史 schema 与当前提示词可能来自不同版本，这一兼容边界没有被静默改写。

保留集仅观察结果，不用于调参。本轮后若依据其中问题优化系统，必须补充新保留样本；现有规模不足以估计泛化能力。

## 本轮独立确认的问题

### 1. 不等式仍被用成等式

来源只支持发行价 P 不低于参考均价 A 的 80%，即 P≥0.8A。本次回答虽然正确说折价率不超过 20%，却又写出“8.39元/股 = 前20个交易日均价 × 80%”，并给出约 10.49 元的均价。

正确边界为 A≤P/0.8，不能得到唯一均价。例如 P=8.39、A=9 也满足前提。将倒算值称为“近似值”“非直接披露”并不能弥补不等式变等式的错误。

原始 trace：`3cf3b7aed0e8c9661e074c6f47e79e4b`。

### 2. 数值引用正确，推导解释仍然错误

德明利回答称第二季度净利润 26.71 亿元“可由上半年归母净利润60.17亿元与前三季度87.46亿元倒算”。87.46−60.17=27.29 亿元，九个月减六个月得到的是第三季度，不是第二季度。

来源中实际已经给出 Q2 的 26.71 亿元，无需编写这一不成立的倒算解释。问题出在从事实到解释的推导，而非缺少这项数据。

原始 trace：`1fa91f27cf229db68d1f4b1b12c02315`。

### 3. 股份总数与输入、自己的表格均不一致

卓胜微输入有 36 行，两个公告日期重复列示同批股份；按证券、解禁日期、股东、股份类型及股数去重后为 18 笔，合计 **40,043,788 股**。回答自己列出的 18 笔也合计 40,043,788 股，却给出“约3,997.6万股，精确为39,976,000股左右”，相差 **67,788 股**。

这里确认的是相对本批输入及回答自身明细的加总错误，不是独立核实公司现实公告。自动评审却给事实和推演维度通过，这两个分数已排除。

原始 trace：`9055ad5f5e7105ac3618d39213d688ea`。

### 4. 前收盘误写成当日收盘

天山铝业材料只给出前收盘及涨跌停价格，本次回答将其概括为“当日收盘价、涨跌停价等”。没有给出错误的具体收盘数字，但数据语义仍被改变。[Tushare 官方字段说明](https://tushare.pro/document/2?doc_id=183)明确 `pre_close` 为昨日收盘价；此文档只用于复核字段语义，没有注入生成或评审输入。年化利润 22×4=88 亿元及 PE 公式本次正确；材料仍缺少市值，离线回放不会自动补齐。

原始 trace：`c1881aa729a56380d40bd2717a4d5ff6`。

## 历史上下文风险

管理层薪酬案例没有新工具材料，输入主要是历史助手摘要。摘要和 goal 已包含“实际控制核心”“固定年薪”“股权激励缺位”等结论，本次回答继续沿用这些判断。实际输入中也有“非原始年报、需原文核验”的来源提示，回答末尾保留了未核原文的说明。

因此不能断言现实数据必然错误，也不宜一律强制再查原文；应区分摘要中的观测值与未经核实的控制权、激励结构推断，避免将后者作为已核事实继续分析。有用历史信息应保留，当前问题是其身份与确定性被提升，而不是所有历史上下文都应删除。
