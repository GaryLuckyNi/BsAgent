# 合成层通用推演约束配对实验

## 结论

本轮候选**暂不进入生产**。它改善了发行折价的不等式理解，以及反推问题中的年份、输入输出角色，但未稳定解决计算与分析问题：股份合计仍错误，另一个回答新增正负号冲突，成本敏感性仍存在错误公式，部分因果表述更强。不能用少数修正或模型评审通过数认定整体质量提升。

版本为 `synthesis-reasoning-ab-2026-11-01-v1`。本轮只测试事先冻结的一版候选，没有依据结果改词后继续抽样，也没有修改生产提示词或增加分析节点。候选见 [通用推演约束](synthesis-reasoning-candidate-v1.md)。

## 实验条件与补跑

固定26条完整真实输入，每组每题一次；另有4条事先设计的合成迁移题，每组各一次，共60个完成的生成响应。真实样本均为已曝光诊断材料；原保留集中的发行案例也已被分析，不能再作为盲测证据，Dataset归属保留但本实验明确标记 `blind_holdout=false`。

两组仅系统提示词不同，用户问题、上下文、来源、任务状态、输出协议及参数保持一致。temperature=0.2，thinking=false，模型输出上限沿用当前代码；评测标准和旧回答没有传入生成模型。请求模型名为 `deepseek-v4-flash`，实际响应名为 `deepseek-flash`，两者分别保存；不能据别名不同推断底座更换。题目以固定随机种子打散，成对交错，先后次序交替，并发为3。

初次运行有28次调用未得到完整响应，随后最小探针确认模型接口返回HTTP 402、`insufficient_balance_error`。余额查询接口当时仍报告可用，不能仅据余额接口判断可生成。最初失败记录没有保存HTTP状态，因此不追溯断言28次均为402。用户确认充值后，仅续跑技术失败，先归档旧失败记录；已完成回答没有重新生成。最终60次生成均成功，每份完成响应只有一次协议尝试，0次格式修复。服务中断使运行跨越两个时段，属于实验限制。

生成阶段实际发起88次请求（60份完成响应、28份技术失败），另有一次最小诊断探针。48份回答的评审共58次协议尝试，含限定次数内的格式／引文修复，不是将每份回答反复重采样到通过。

沿用冻结的五维评审器，评审输入不含实验组标记或候选提示词。7份评审因答案或证据逐字引文校验失败而拒收，原始响应保留，不重试到通过。拒收不等于回答质量为零；合成迁移题不参与云端质量评审，也不混入真实Dataset。

复核排除既包括错误扣分，也包括漏检后误判通过。例如：408.2%约为4倍并无换算错误；来源已经披露的利润下限不能被判作凭空补充；同样缺少市值的两组回答不能采用不一致的需求评分；股份加总错误与现金流因果过强也不能因评审给出通过就算正确。排除只表示该维度分数不采用，**不会改成通过**。本次复核由本代理对原句、输入和数学关系检查，不是人工专家金标，也不是另一个独立底座裁判。

## 独立复核的关键发现

| 检查内容 | 当前提示词 | 候选提示词 | 判断 |
| --- | --- | --- | --- |
| 发行价格不低于参考均价80% | 仍表述为折价约20% | 明确折价率不超过20%，不能确定精确值 | 候选改善；三个窗口的精确数据仍未取得 |
| 上年利润基数 | 将2025值当成本期值再次除增长因子，答0.80—1.02亿元 | 直接引用已披露2025值1.92亿元，并区分缺少本期值无法独立反推 | 候选修正输入输出角色，未完成本期数据交叉核验 |
| 累计期间差分 | 本次正确将前三季度减上半年归入Q3 | 本次期间方向也正确 | 上次回放的期间错误没有在本次控制组复现，不能算候选独有收益 |
| 低基数贡献归因 | 无依据拆成96.6%/3.4% | 又引入任意1.7亿元基准解释约3%，随后说不能唯一拆分 | 两组均不能算正确归因 |
| 18笔股份明细求和 | 39,999,900股，并称比例7.48% | 约40,006,000股 | 按两组声明的去重范围，实际40,043,788股，两组均错 |
| 年化利润与PE | 年化88亿元，无市值则不造PE；注明前收盘价 | 同样88亿元、无市值不造PE，明确前一交易日价格 | 核心算术及价格语义合格，业务所求PE均未完成 |
| 季度营收环比 | -0.37% | 小标题+0.37%，正文公式-0.37% | 候选新增对外结论冲突 |
| 原材料成本敏感性 | 开头错称下降4.8个百分点，后文公式与表接近正确 | 既保留4.8说法，又增加错误近似公式及互相冲突的两套表 | 两组未通过，候选没有改善 |
| 产品结构变化与减值 | 排序带账龄等条件，仍有证据强度风险 | 将结构变化断言为一次性、可逆及已被定价 | 候选的无依据确定性更强 |
| 正现金流、负净利润 | 比率正确，但据此断言亏损主要来自非付现因素 | 相同问题 | 数学正确不代表原因已证实 |

股份复算：原材料共36行，两个公告日期版本的18笔明细逐项匹配。按回答自行声明的重复公告去重范围求和为40,043,788股，已披露比例字段求和为6.9643%。当前回答少43,888股，候选少37,788股。这里复算的是材料和回答的内部一致性，没有冒充重新核对公司正式批次公告。

敏感性复算：收入R不变，基期成本C，直接材料占成本比例s=48%，原材料涨幅p，则毛利率变化为 `Δm=-(C/R)×s×p`。成本增长4.8%不能直接当作毛利率下降4.8个百分点。按输入基期，10%、20%、30%情景下降约4.16、8.31、12.47个百分点。两组还都把用户给定的48%称作46%—49%的中值，而严格中值应为47.5%。

现金流复核只否定推导强度，不断言公司真实亏损来源：给定净利润与经营现金流，也可能由营运资金释放形成相同差额，不能只凭两个总数确定非付现损失是亏损主因。

4条合成迁移题的核心目标两组均通过：不等式只能得参考均价上界30；累计差分得到Q3为480而不能唯一确定Q2；重复事项去重合计650；开放式给定条件直接分析、不申请额外补证。它们是AI设计的小型诊断，不代表全文无瑕疵：期间题额外给出的Q2区间依赖未明示的非负假设，现金流比率也不能单独证明全部营运资金项目健康。

## 补证与多余缺失声明

两组都只在“解禁市值前三名缺明细”及“所搜减持公告主体不符”申请补证，均涉及核心缺口；未实际执行补证，不宣称业务完成。开放式三季报分析两组本次都作答，而上一轮当前提示词曾申请补证，说明单次采样本身存在波动。

利润增速中值估算两组仍附带并非原问硬要求的预告交叉核对缺失声明，候选管理层分析也仍有较长缺失清单。本轮只追加推演约束，没有修好用户不希望看到的泛化“数据不完整”表达问题。不能把它包装成全面改善。

## 后续方向

先校准会误导评审的验收标准，明确“原问必需”与“有则更好”，并将数字总和、符号、期间和不等式纳入独立可复算的验收；不要继续仅凭同一个模型给自己打分。对生成改动则保留更小、可单独验证的实验，不把所有约束一并加入。新的候选须另起版本，并补充新的独立会话样本后再决定上线。

本轮不支持全链路准确率、统计显著性或泛化能力结论，也未验证生产节点的额外数值门控是否会拦截这些错误。
