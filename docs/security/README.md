## 已确认的方向

- 安全能力作为独立模块维护，允许修改 harness 与公共基础设施适配层，各 Agent 和业务节点不直接依赖安全模块。
- 第一版围绕当前投研链路验收，包括已有记忆写入、审批、停止、重试、断点恢复和后台任务。
- 未来任意代码执行、通用文件修改和交易操作不纳入本期功能实现，必须保留安全 TODO，新增能力启用前完成对应验收。
- 按用户确认分批实施；本记录不代表其余安全契约已经全部实现或验收。

## 模块边界草案

```text
Agent / Planner / Skill
        ↓
公共安全适配层
节点执行 / 模型调用 / 工具执行 / 记忆读写 / 输出与持久化
        ↓
独立安全内核
确定性策略 / 风险检测 / 预算 / 最小化审计
        ↓
现有 LLM Client / Tool Gateway / Store / 审批与恢复设施
```

安全内核负责判断，适配层负责在实际操作前执行决定。第一版优先考虑进程内模块，不预设必须新建微服务。已有认证、授权、审批和副作用管理继续负责自身契约，安全模块只能进一步收紧限制。

仅在节点首尾检查不足以覆盖节点内部调用；需要分别覆盖同步、异步、流式、工具绑定、重试和后台入口。无法从现有接口获得数据来源或权限信息时，应记录缺口并补齐公共契约，不能声称包装后已自动获得完整防护。

## 本期能力与验收边界

| 当前能力 | 安全关注点 | 验收目标 |
| --- | --- | --- |
| 用户请求与会话访问 | 身份伪造、跨用户或跨租户访问 | 身份来自可信认证上下文；会话、运行、事件和资产访问验证资源归属 |
| 动态规划与 Skill | 模型自行扩大权限、恶意工具描述诱导 | Plan/Skill 只能收窄服务端权限；目录风险与执行绑定不能被模型降低或替换 |
| MCP、RAG、联网搜索 | 越权检索、恶意结果、搜索词外泄、危险目标地址 | 资源访问有授权，外部内容不能产生授权，出站内容与目标受策略约束 |
| 图片上传、OCR 与 Vision | 恶意文件、图片文字注入、外部模型泄露 | 保持资产归属和文件校验；识别发送给外部分析服务的数据边界 |
| 长期偏好与上下文压缩 | 记忆污染、跨用户召回、摘要提升内容可信度 | 检查读写归属、候选审批和来源；压缩内容不得获得新的授权效力 |
| 审批、恢复、停止与重试 | 参数替换、权限撤销、重复写入、未知副作用 | 审批绑定调用实例与参数；恢复校验当前权限；未知写入不能被盲目重试 |
| 回答、日志、Trace 与 checkpoint | 凭证泄露、敏感内容扩散、输出注入 | 按不同出口的数据契约处理；需阻断的数据在发送或落盘前检查 |
| 后台同步、恢复及压缩任务 | 绕过请求链路检查、身份上下文丢失 | 后台入口纳入覆盖清单，使用明确的用户或服务身份和授权范围 |
| 执行资源 | 无限重规划、重试或并发调用 | 明确单次运行预算、停止边界和并发约束，并验证无法通过替代路径绕过 |

现有生产部署中的身份、网络、凭证和依赖配置属于验收前提，应核对当前配置。任意网页正文抓取、任意本地程序执行等未来能力不因本期验收自动获得授权。

## 安全契约草案

1. 身份、权限、审批和策略版本来自服务端可信上下文，不能仅凭可被模型或节点修改的 State 字段建立授权。
2. 区分确定性授权规则与提示注入等风险信号。检测器存在误报和漏报；模型被误导时，执行层仍必须阻止越权操作。
3. 安全拒绝不能进入自动重试或替代工具流程后变成放行；合法重新授权必须走显式流程。
4. 审批后的调用参数不得被静默改写。需要改变实际参数时，重新计算指纹、执行授权并按需重新审批。
5. 强制授权检查不可用时，受保护操作不得执行。可选检测器的故障策略需显式配置，并记录降级和未覆盖范围。
6. 流式内容按出口要求在发送前检查；最终检查无法撤回已发送内容。日志与观测 SDK 也必须在原始数据外发前执行相应处理。
7. 安全决策审计独立于普通 Trace 采样，仅保存必要的身份引用、操作引用、规则及策略版本、决定和脱敏原因；持久化失败时的行为需要按操作风险明确规定。
8. 安全配置和规则变更需要受控权限；生产环境不能通过普通业务请求关闭强制检查。

## 验收方式

- 先盘点真实调用路径，建立“入口—适配点—资源—身份来源—现有控制—缺口”清单。
- 确定性控制使用可复现的允许与拒绝案例验证，拒绝场景应断言受保护调用未发生；已知副作用的恢复场景验证没有重复派发。
- 提示注入等检测另行评估正常样本、攻击样本、误报、漏报和延迟，具体门槛在威胁模型完成后确定，不宣称能够消除所有注入。
- 覆盖普通执行、同步与异步调用、流式、后台任务、中断恢复、重试和权限撤销；未覆盖路径不能算作验收通过。
- 保留正常投研查询、合法图片分析、偏好记忆和审批恢复的成功路径回归证据。
- 每项使用“待盘点、待设计、待实施、待验收、已验收”状态，并附证据；已有机制不等于已经通过本轮安全验收。
