## 当前行为

- **普通正文增量发布**：保留24字符短尾，在词/文字边界检查后释放前文。出现可能开启凭证、JSON对象、编码、私钥、URL等上下文的标记后，保守收集后缀到结束再检查；无边界长token超过256字符也封存，避免逐片重扫增长的全文。这些后缀仍可能延后展示，短回答也可能在结束时才出现。
- **入口贯通**：DeepSeek同步/异步HTTP、通用completion factory及原生模型`stream/astream`均可提前返回普通正文。工具参数、调用配对和结构化元数据仍完整校验后发布；SDK原始token回调和完整事件/日志接口继续走受控观测出口。
- **持久化订阅**：生产者先检查正文，再为释放片段分配真实序号。只有生产者的独立`content_checked`参数能附加当前凭证策略标记；事件数据中的同名声明被移除。新安全片段可直接订阅/重放，旧行及不匹配当前策略的行仍从阶段起点完整重建检查。
- **停止和错误**：已展示的安全前文不能撤回；后续失败不再保证“一个字都没显示”。未完成风险后缀不直接发布；停止时仅检查已接收尾部并封口，不再推进提供方。提前关闭或回调取消会显式关闭委托源，关闭错误不能推进下一片或执行工具。
- **授权与预算**：SSE推进前/发送前仍校验当前权限，不引入授权TTL缓存。预算预留后再做最终权限/外发检查，等待期间撤权不得派发；两处派发前等待被取消时，回执按`not_started`结算，额度预留仍保守不退款。

## 热点修改

| 热点 | 修改 |
| --- | --- |
| 模型消息重复转换 | 整组凭证副本转换一次后复用字段；原始调用ID/工具名仍独立校验 |
| 未使用的注入分类 | 模型凭证副本、公开展示和观测副本不再重复分类；工具、OCR、记忆/摘要、工具描述入口保留检测/扣留 |
| 预算绑定 | 预算与run合并为一次查询，保留身份、请求、策略、期限和计数校验 |
| 响应信用 | 常规64KiB预留改为完整绑定条件的单次原子`UPDATE … RETURNING`；余额不足保留加锁回退，未增大限额 |
| 同步数据库阻塞 | 异步请求预算、补信用和工具鉴权/扣费移出事件循环；票据ContextVar仍在调用任务设置，已有信用小片走内存路径 |
| 逐帧目录/资源读取 | 同数据库的目录与归属合并查询；其它提供方/不同数据库绑定保留原路径，每帧两次检查不删除 |

默认主图同步客户端已有持久连接；原生异步SDK为兼容跨`asyncio.run`生命周期仍按响应关闭。Admin token已有缓存，冷启动/到期续期仍需有效身份服务响应。本轮没有硬改成跨事件循环共享客户端或在缺少有效凭证时放行，这两项留待真实部署观察。

## 局部计时

[优化前JSON](2026-11-10-security-latency-results.json)、[优化后JSON](2026-11-10-security-latency-after-results.json)、[复现脚本](../probes/security_latency.py)。CPU取3次中位数，数据库场景各1次；均为合成数据、临时SQLite及禁网。不是生产p95或统计显著性结论。

| 相同场景 | 优化前 | 优化后 |
| --- | --- | --- |
| 64,000字符模型消息保护 | 114.38ms | 23.38ms |
| 250,000字符模型消息保护 | 537.73ms | 73.21ms |
| 1,000,000字符模型消息保护 | 1942.96ms | 344.62ms |
| 100帧SSE鉴权 | 402 SELECT | 201 SELECT |
| 100帧预算包装 | 410 SELECT | 205 SELECT |
| 原始/解码各1MiB信用预留 | 128 SELECT +64 UPDATE +32 COMMIT | 32 UPDATE +32 COMMIT |
| 信用预留，每SQL/提交注入2ms等待 | 834.95ms | 253.92ms |
| SSE鉴权，每SQL注入2ms等待 | 1382.26ms | 913.26ms |
| 预算包装，每SQL注入2ms等待 | 1420.29ms | 987.63ms |

**本地SQLite没有全面变快**：无注入等待时，鉴权119.17→215.06ms、预算包装150.35→274.29ms、信用预留88.37→88.94ms。合并查询减少往返，但ORM查询构造、连接与映射仍有成本。外部工具检测未关闭，64,000字符工具投影54.29→67.52ms，也未声称获得优化。两轮机器/调度状态不同，不把查询减半描述成所有场景耗时减半。

长回答演示采用相同节奏：80片、每片4字符、每30ms一片。全文缓冲模拟首片约**2557ms**，当前原生模型增量入口约**225ms**。这不是包含规划、RAG、网络和多层适配的主应用端到端保证。原5片/共20字符样本仍约159ms才显示，符合短尾策略。
