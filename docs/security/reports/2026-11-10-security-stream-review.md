| 已复现问题 | 修复与验证 |
| --- | --- |
| P2：字符串已发布后切换内容块，结束时重复前文 | 最终安全内容逐块移除已经发布的前缀；混合内容回归核对完整拼接 |
| P2：两个派发前数据库等待被取消后，工具未执行但回执仍running | 按not_started结算；分别阻塞最终权限刷新及扣费线程，确认executor次数为0且回执settled |
| P2：无词边界文本逐片扫描增长的pending，呈平方级耗时 | 超过256字符且无边界后封存后缀；原32字符片段1000/2000/4000次约0.738/3.020/12.013秒，修复后同探针为毫秒级；仓库另断言扫描工作量有界 |
| P2：提前关闭外层增量流不立即关闭底层委托源 | 同步/异步源显式关闭；保留源引用排除GC影响，关闭后立即观察finally已执行；关闭自身抛错时不会推进下一片或发布尾部 |
| 两种重试标志同时启用时，空结果重试成功会双发 | 保留原生回调接口选择，以defer_output控制发布，最终仅发送一份 |
