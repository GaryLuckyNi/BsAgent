# 全任务持久化预算验收记录

日期：2026-11-08。分支：`codex/run-security-budget`。范围为BsAgent当前受管执行路径的本地实现与测试；未提交、部署或执行真实数据库迁移，没有修改独立RAG工程。

## 用户确认与实际规则

用户确认采用可配置默认值。新任务创建时，在begin_turn同一事务写入独立预算表，冻结所有者、会话、请求、策略摘要、限额和绝对期限；后续配置只影响新任务。暂停等待审批也计入30分钟，恢复不能重置计数或期限。普通请求、Graph State、checkpoint和工具返回不能授予预算。

| 资源 | 默认上限 | 计量与适用范围 |
| --- | --- | --- |
| 模型请求 | 32次 | 当前直接DeepSeek JSON/SSE、ChatOpenAI同步/异步原生绑定、旧版DeepSeek搜索模型每一轮的受管HTTP派发；失败和重试也消耗额度 |
| 工具派发 | 64次 | 公共Gateway最后校验后、进入executor之前扣次；已有搜索结果/回执的复用不重新派发，不扣新工具次数 |
| 请求正文 | 16MiB | 当前受管HTTP的已缓存正文实际长度；不包含协议头/TLS。未知流式请求正文在外发前拒绝，不能先无界读取再检查 |
| HTTP请求信用 | 512次 | 包括零正文GET、通知、重连、错误请求和MCP清理预留；不把一场MCP会话当作一个请求 |
| 原始响应实体信用 | 128MiB | 每响应按最多64KiB预留，剩余额度不足时可授予剩余部分；未使用部分不退还 |
| 解压后响应信用 | 128MiB | 独立计量；压缩解码依据当前信用限制输出窗口，无信用时最多探测一个字节，不能先膨胀8MiB再发现全任务额度不足 |
| 执行期限 | 1800秒 | 每次执行推进、节点边界、派发和响应读取检查；DB连接/锁等待/提交后复查，函数返回或生成器完成后过期也不能发布正文 |

这些是本工程的资源控制值，不是token数、费用估算或供应商账单。费用定价、可信usage汇总与计费预算继续保留为TODO。单响应原始/解压各8MiB及SSE单行256KiB限制继续独立生效。

## 账本与恢复

`security_run_budgets`及0019迁移建立六项上限/只增计数、所有者和状态约束。模型、工具、HTTP及正文的一次联合扣减使用条件UPDATE，冻结策略、身份、期限和各项额度同时匹配才提交。响应授信在独立短事务取得行写锁，再读取最新计数；不靠进程内Lock保证跨实例额度。

恰好用完额度的合法请求可以收尾；下一次申请越额后，持久化状态变为exhausted，其它资源也不能作为降级通道。缺失、畸形或归属不符的账本固定拒绝，历史任务不自动补发。数据库故障时不派发，原始驱动/连接hook诊断不进入公共预算异常。已预留额度不因异常、未知提交或取消退还。

可信ContextVar只在公共Graph适配和执行快照准备期间绑定。生成器每次推进后复位，再交还HTTP消费者；响应计量器捕获创建时的可信绑定。正常API、普通SSE、持久化协议、审批及后台恢复沿用原run。历史结果读取不因执行期限到期而自动删除或续期。

审批/用户输入恢复遇到耗尽或过期时终结旧任务并释放active_run，允许发起新任务；预算服务暂不可用时保持失败关闭及恢复机会。预算不抹除旧回执或既有审批参数指纹。

## 传输、终止与清理

同一实际Request对象的嵌套受管包装使用短生命周期host票据，避免重复扣HTTP/正文，已知模型路径只扣一次模型次数；离开派发范围后的真正重试重新扣次。远端头、JSON字段和异常码字符串不能伪造该票据或预算信号。

有预算的run仅支持无自动认证或单轮Basic认证，并拒绝HTTPX事件hook。独立复核确认Digest认证可在一次send内部重发并预读，本批选择在外发前拒绝该未计量路径；多轮OAuth/Digest及hook兼容需另行实现逐次计量。受管客户端禁止自动跟随重定向。宿主自定义transport内自行请求或预缓冲不在当前保证范围。

MCP每创建一个会话客户端，先预留一次HTTP清理信用。host单次能力仅允许指定端点的空正文DELETE，即使任务已过期/耗尽也可消费此前预留；成功/错误清理响应都不读正文，异步发送和关闭有独立有界宽限。预留未使用不退款，也不等于远端一定清理成功。

真实SDK可能包装或吞掉异常，预算类型通过有限异常链检查与MCP host scope保持终止语义。不能把全任务预算错误变成普通工具失败后继续换工具。派发前拒绝的回执为not_started；executor已进入后中止的合成写操作保留uncertain/unknown，不能声称远端未执行。回执保存、局部关闭和已有清理预留不重新申请业务额度。
