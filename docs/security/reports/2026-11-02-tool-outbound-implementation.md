## 实现与边界

独立 `ToolOutboundPolicy` 使用已实现的凭证底线，产生允许/拒绝和最小规则审计，不修改调用参数。已知凭证、schema 敏感标记或无法按预算检查的工具参数拒绝；同一输出脱敏策略中的业务规则不自动混用为输入规则。业务外发字段拒绝接口 `BS_AGENT_TOOL_OUTBOUND_RULES` 默认空，允许按工具名、字段路径、租户和受信权限例外配置；例外不会关闭凭证底线。它不自动识别手机号、财务数据或任意内部资料，不等于完整来源分类及外发用途控制。

公共网关在结果观测/回执预留/工具调用之前检查原始参数、输入类转换后的实际参数，以及受信注册快照声明的出站上下文字段。模型 self-report 不改变声明。可用性检查和回执预留后，派发前重新刷新权限并按当前规则复核；撤销业务外发例外会拒绝，已预留回执结算为 denied/not_started。安全层不修改审批参数指纹。

默认 Search API 仅发送可选 original_question，因此网关只检查对应上下文字段；旧搜索协议发送完整 research_context，检查完整上下文。两个现有搜索客户端还检查实际最终 payload，旧协议续轮同样检查；认证 Header 由受信配置正常注入。已经完成首轮而仅续轮被拦时保留 failed/uncertain，不虚称整个调用未执行。

ToolCallRequest 先执行有界凭证检查，避免深层结构进入旧递归扫描；网关仍独立复核 model_copy/construct 等绕过 DTO 校验的输入。超限/策略处理异常按固定安全信息拒绝，不记录原始异常正文。
