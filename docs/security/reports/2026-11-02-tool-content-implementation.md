# 统一工具内容策略首批验收记录

日期：2026-11-02。范围：BsAgent 内的独立安全模块及公共工具适配层；未修改外部 RAG 工程。未部署、迁移数据库或切换认证模式。

## 已实现

- 新增纯内容策略与公共适配，覆盖通过 ToolExecutionGateway 执行的任意工具成功、失败、异常；保持先校验原始契约再生成视图。
- 通用凭证底线包含已有字段/schema、认证文本以及新增 Cookie、PEM、嵌套/内联 JSON 处理；业务字段规则由受信配置明确声明，默认空数组。
- 工作流结果按所有已声明出口规则采取保守限制，回执与结果观测再投影；普通工具消息正文和 artifact 同步处理。失败回执 raw_result 只保留类型诊断，没有原始正文副本。
- 宿主设置实际工具来源、执行绑定、策略版本及不可信资料标记。默认注入模式为有限信号 flag，可配置 withhold；不把风险信号当作授权。
- 策略不可用时派发前拒绝；执行之后处理故障/内容扣留保持真实执行状态。同一已成功写调用的重试拒绝，缓存搜索重用按当前策略重新投影。

## 留存 TODO 与边界

1. 业务规则默认未配置，合成手机号只是测试示例。需由业务方定义真实数据分类、字段、接收方与授权例外；当前不能宣称业务敏感数据均已脱敏。
2. 运行时尚未提供独立出口明文视图，共享工作流按全部出口规则保守隐藏。历史 checkpoint、旧 TaskResult 字符串、全局日志、输入/OCR、工具描述、记忆/压缩其他入口仍需逐路径接入。
3. 注入检测只有有限模式和不可信标记；编码变体、真实模型受诱导程度、误报/漏报和多轮洗白尚未完整评估。内部资料装入已允许搜索参数的数据外发用途控制仍未实现。
4. 凭证保护仅覆盖已知形式，不能声称识别任意未知秘密或业务个人信息。JSON/处理超限采取保守扣留；正常对照仅覆盖已执行样本。
5. 外部 RAG 服务身份与文档 ACL、独立审计存储/保留期及规则管理仍以安全总 TODO 为准。总体 SEC-05/07/10 等事项不勾选完成。
