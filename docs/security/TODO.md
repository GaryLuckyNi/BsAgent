## 后续：新增能力启用前必须完成

以下项目独立保留，不计入本期完成率。触发相应能力的设计或接入时，应先转为该能力的发布前置条件。

- [ ] **SEC-F01：任意代码或 Shell 执行隔离。** 触发：新增 Python、Shell、用户脚本或可执行 Skill。完成条件：定义并验收文件、网络、进程、凭证、CPU、内存、执行时间和残留资源限制；验证无法通过命令嵌套、子进程或编码绕过边界。
- [ ] **SEC-F02：通用文件修改安全。** 触发：新增 Agent 创建、覆盖、删除文件或修改仓库的能力。完成条件：验证路径规范化、符号链接、工作区范围、敏感文件保护和覆盖/删除审批，明确并发修改、检查后替换及失败恢复行为。当前资产上传与对象存储安全仍属本期。
- [ ] **SEC-F03：交易与资金操作。** 触发：新增下单、撤单、转账或账户变更。完成条件：验证账户与标的范围、额度、可信交易参数展示、审批时效、执行前风险复核、幂等和外部结果对账；明确不得声称跨系统 exactly-once 或通用回滚。
- [ ] **SEC-F04：通用外部写入。** 触发：新增邮件发送、消息发布、第三方文档修改等工具。完成条件：验证目标收件人或资源、外发内容、审批指纹、重复发送和结果未知处理；未经授权不产生外部副作用。
- [ ] **SEC-F05：任意 URL 抓取与浏览器操作。** 触发：新增正文 Fetch、任意 URL 导航或浏览器自动化。完成条件：覆盖 SSRF、重定向、DNS 重绑定、私网与云元数据地址、下载和 Cookie/浏览器身份隔离。当前 MCP、RAG、搜索及模型服务的连接目标约束仍属本期。

- [ ] **SEC-F08：跨项目安全服务与分布式策略。** 触发：需要多个 Agent 工程共享策略或跨进程预算。完成条件：验收服务认证、策略分发一致性、缓存与撤销时效、并发预算和服务异常行为；业务项目不能绕过执行拦截。
