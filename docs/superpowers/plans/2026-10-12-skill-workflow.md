# Summary 驱动的固定 Skill 工作流实施计划

目标：summary 作为唯一维护入口，解析出的步骤固定执行，指定工具按名称加载；高风险调用复用现有审批和 checkpoint，恢复时不重新规划或生成参数。

架构：保留外层 Planner 任务；每个 Skill 父任务维护独立的运行时工作流快照。调度器串行派发内部步骤到现有 Tool/Analysis Agent，完成后校验输出，再推进下一步。内部步骤不触发 Planner 反馈。工具失败或约束不满足默认停止，只有 summary 明确允许缺失时才能继续。审批拒绝终止依赖步骤。

实现与验证：
- [x] 工作流契约与编译：限制步骤数，保存 summary/版本/定义哈希，校验工具名称及源文引用；按完整名称或唯一后缀解析工具，歧义/不存在/权限不足均失败。
- [x] 图状态与调度：保存工作流快照、已校验步骤；固定子任务 ID；先完成当前工作流，禁止内部重新规划；聚合父任务结果。
- [x] Tool Agent：仅绑定指定工具，required 模式只生成参数；恢复复用暂存调用；从工作流派生执行边界，保留权限、审批和目录版本校验。
- [x] 步骤验收：检查原始返回中的必需字段和自然语言完成条件；保留失败、缺失和允许继续的说明。
- [x] 管理配置：移除 Allowed Tools 和证据要求字段；迁移先把旧配置回填到 summary，再删除旧列；默认 Skill 改为完整 summary。
- [x] 自动验证：编译错误、未知/歧义工具、三步串行、首步审批通过/拒绝、后续审批、结果缺失、恢复不重复调用、开放任务回归、数据库迁移和前端构建。

边界：自然语言解析有歧义时失败，不自动替换工具。checkpoint 可防止正常审批恢复重复执行；外部副作用在进程崩溃窗口内的 exactly-once 仍需要工具服务按调用 ID 提供幂等性，不能仅靠图保证。
