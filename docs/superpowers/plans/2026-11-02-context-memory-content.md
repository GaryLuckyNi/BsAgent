# 摘要与长期记忆内容边界实施计划

目标：延续已确认的统一凭证保护，防止历史资料在摘要生成/修复与长期偏好记忆进出时重新传播凭证；不定义新的业务敏感类别。

架构：在独立安全模块新增 context_content 公共适配，复用唯一的 ToolContentPolicy 凭证底线。摘要模型输入先生成安全副本，模型输出仍严格校验并修复一次；记忆候选和持久化/补写拒绝带凭证内容，旧记忆召回跳过不安全项，不改写原存储记录。业务 Agent 节点不改动，不新增身份服务，不迁移或删除历史数据。

- [x] 用隔离摘要模型与内存 Store 验证已知凭证在源历史、旧摘要、修复输入、模型摘要输出及偏好内容中的传播；先运行失败样本，保留普通事实和合法偏好的对照。
- [x] 新建 security/context_content.py：生成有界安全视图与安全内容判断，处理失败固定拒绝，不复制原始异常；源内容不获得新授权。
- [x] 接入 ContextSummarizer 源投影、修复投影与输出校验，避免校验失败后的修复请求把凭证再次外发；旧摘要激活读取不能绕过同一校验。
- [x] 接入偏好候选、候选持久化、后台 Store 补写及召回；拒绝不安全的新写入，历史不安全项只跳过并保留固定状态，不擅自删除原记录。
- [x] 验证会话归属、候选审批、后台补偿、压缩软/硬阈值与正常摘要回归；独立复核后更新验收记录及总体 TODO。

范围限制：本批不等于全局模型输入防护，不清理所有历史 checkpoint/TaskResult，不通过摘要授予权限，也不声称识别任意编码秘密或防住全部记忆注入。业务分类、摘要/证据来源追踪与真实模型多轮诱导继续独立验收。候选 ID 跨身份更新等存储隔离观察若未证实外部可达，单独记录待验证，不声称已有真实用户越权。
