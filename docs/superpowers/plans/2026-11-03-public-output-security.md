# 公共正文、来源链接与浏览器自动请求安全计划

目标：继续完成 SEC-05/07/10/12，堵住模型检查之后插入引用链接、旧消息/来源元数据重放及浏览器自动资源请求的旁路；统一两个搜索 provider 的错误链处理。沿用通用凭证检查和已确认的“检查后再展示”，不推断业务敏感类别。

设计：公共输出适配只生成正文/元数据安全副本，不修改执行状态、角色、调用 ID 或审批指纹。来源 URL 必须是格式有效的公开 HTTP(S) 地址，无用户凭证、已知敏感参数、控制字符或已知本地/私网目标；不能通过把参数改成星号继续使用。来源正文先完整检查再截断，编号不重排。模型之后的链接转换、最终回答与历史响应同样接入。

前端对旧消息作 URL 防御；Markdown 原始 HTML 与远程图片不自动加载，来源 favicon 用本地图标。安全外链仍可主动打开，普通财报正文和引用交互保留。浏览器端检查不替代服务端凭证策略，也不声称阻止 DNS 重绑定或用户主动打开的未知业务数据。

- [x] 实现独立 public_output 适配，接入引用插入/来源目录/最终合成/公共进度及相关历史响应；不通过展示处理改写副作用状态。
- [x] 红测试并修复两个搜索客户端 HTTP/超时/无效 JSON/超深 JSON 的原始异常链，保留固定错误码、状态及可重试语义。
- [x] 前端红测试并修复危险链接、Markdown 图片/HTML、远端 favicon；普通链接、引用卡片、来源面板与键盘操作回归。
- [x] 尽可能用隔离浏览器验证无自动外部资源请求，保留可复现证据；无实际浏览器证据时不能用 JSDOM 冒充网络验收。
- [x] 服务端关联测试、前端测试/构建、独立只读复核、文档和红队证据更新。
