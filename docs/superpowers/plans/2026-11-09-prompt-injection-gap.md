# 按原计划收口：提示注入必要防护

依据：[已确认范围](../../security/README.md)、[统一工具内容策略计划](2026-11-02-tool-content-policy.md)及设计第2/4节。用户要求快速收敛，不新增并发、记忆版本、费用、审计数据库或独立服务；未完成记忆版本原型归档并撤回，保留上一批已验证修复。

本轮只完成以下缺口：

- [x] 统一检测常见的外部指令覆盖、角色伪造、系统提示/秘密索取、跳过审批及工具/记忆劫持；覆盖中英文、Unicode/HTML/编码变体，扫描有界。
- [x] 原公共工具策略默认扣留高风险内容，成功/失败/message/details/artifact和旧ToolMessage共用，不改变已发生的执行状态；OCR与记忆/摘要的外部资料入口使用相同阻断语义。
- [x] 工具描述在绑定模型前拒绝高风险指令；模型公共适配加入宿主的来源隔离规则，保留消息角色、调用ID及审批权限边界。用户合法询问安全概念不按外部资料误拦。
- [x] 攻击样本与普通投研/错误/工具描述正常对照，以及规则故障、回执、副作用、同步/异步/流式回归；报告只证明样本覆盖和硬边界，不把规则或提示词称为杜绝所有注入。

验证使用临时数据/内存客户端与HTTPX禁网，不访问真实秘密、外部业务服务或执行攻击载荷。完成后回到原计划验收清单，不继续扩张旁支。

本地实施与回归已完成，见 [验收记录](../../security/reports/2026-11-09-prompt-injection-implementation.md)：专项41项通过，118文件联合回归2309项通过、14项跳过。本计划勾选仅对应上述本地实现，不代表完整红队案例、真实模型行为或生产部署验收通过。
