# 可重连会话与停止增强实施计划

> 执行方式：当前会话使用 superpowers:subagent-driven-development；各任务先编写失败测试，再实现并验证。用户要求保留当前工作目录，不创建 worktree。

**目标：** 刷新继续生成、停止可确认且保留上下文、后续请求不被孤立 run 永久阻塞。

**架构：** 现有协议流外增加独立生产者和数据库事件日志；增加受身份约束的查询、重连和停止接口。前端保留 SDK 正常提交，恢复时订阅已存在 run。停止在执行边界检查，业务状态与执行者身份共同防止旧任务继续写入。

**技术栈：** FastAPI、SQLAlchemy、PostgreSQL、LangGraph、React、LangGraph SDK、pytest、Vitest。

## 明确保留的边界

停止是协作控制，不是跨系统回滚。已提交副作用保留；未知写结果需外部核实。临时补落库材料在进程内，进程同时丢失时按未知结果处理。跨主机或消失容器不能仅凭过期心跳强行接管。生产需要独立 turn-worker 和 scheduler，不提供外部系统 exactly-once 保证。
