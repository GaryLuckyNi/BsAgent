# 真实业务评测集实施计划

目标：从本机 Langfuse 真实 `bs-agent.run` 建立首批约 50 条可追溯样本，分别提供调优集与保留集；保留输入、取证和回答快照，独立编写验收标准。

边界：不修改运行链路、提示词或模型，不重放真实工具，不把历史回答和模型自评当正确答案。业务原始资料落在已忽略的 `data/evaluation/2026-11-01`，仓库仅保存工具、测试、评测规范和汇总。只发布到当前本机 Langfuse 项目。

- [x] 分页读取真实根观察，排除合成示例与同一问题的重复运行，记录筛选理由。
- [x] 导出入选 trace 的完整 observation 快照，检测缺失、截断、缺少最终答案与证据，不夸大回放能力。
- [x] 为每条原问编写必需内容、禁止行为和证据边界；区分观察事实、假设计算与外部事实。
- [x] 以会话及近似问题连通分组，避免同组进入调优集和保留集；故障样本与正常样本均保留。
- [x] 实现幂等导入及测试，人工复核状态与 AI 制定的标准明确区分，不虚构人工标签。
- [x] 发布到真实 Langfuse Dataset，逐项回读核对数量、来源、标准、分组和内容摘要。
- [x] 保存中文清单、使用说明、完整性报告和后续待复核范围。

验证：导出/分组/截断识别/标准与旧回答隔离/幂等发布相关单测；真实 API 回读和 SHA-256 比较。不得把源资料不足的案例列为已具备完整全链路回放。
