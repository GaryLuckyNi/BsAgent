# 合成提示词证据使用优化

目标：依据近期在线低分记录优化回答，不以提高某个评分值为唯一目标。用户已表达优化意图，本轮先形成可复核的离线候选，不部署或覆盖生产提示词。

诊断：在线 `bsagent-answer-quality-v1` 与新离线评审不是同一套。读取最近100条对应指标，回答质量均值约0.761、0.55占15条；证据支持度均值约0.752、0.55占13条。最新一条质量0.72、支持度0.55。三条实际记录分别呈现异期估值资料替代完整可比表、交易公告未取得、财务取数缺绝对金额。分数仅是采样结果，不能代表整体质量；不同日期数值不同本身不构成事实矛盾。

方案选择：追加更多禁令容易重复现有长提示词；改整条业务链会混淆变量。本轮只重写合成核心提示词，保留按需核验公共约束、业务表达约束、来源编号、分析交接和回答／补证协议。候选以交付目标、证据读取、可回答范围、推理与比较、输出五部分组织，不写案例公司、数据答案或指定工具。
