# DeepSeek 联网实体解析设计

## 背景

当前投研链路先调用 `stock.resolve_company`，未命中后由 LLM 根据市场目录候选生成新的公司名并重试。市场目录只表达名称相似度，不表达法律主体关系，因此可能把同行业公司误当成用户所指实体。对于新上市、品牌名、集团名或口语化名称，仅依赖 Tushare 证券目录和模型参数记忆也无法稳定获得上市主体及证券代码。

DeepSeek V4 的 Anthropic API 支持服务端 Web Search。项目需要把它作为受治理的检索能力接入实体修复链路，而不是让市场数据 Provider 承担模型推理，也不能把搜索结果直接当作证券代码事实。

## 目标

- 公司精确解析失败后，允许 Agent 使用 DeepSeek 原生 Web Search 发现法定主体、上市主体和证券代码关系。
- 仅接受同一实体、正式简称、品牌与法定主体、母子公司或明确上市主体关系；同行、竞争对手、供应商、客户和概念相关公司一律拒绝。
- 搜索发现的名称或代码必须再次通过 `stock.resolve_company` 验证后，才能注入后续行情和财务工具。
- 搜索调用进入现有工具权限、风险、超时、脱敏和 trace 体系。
- 删除市场目录高相似候选自动兜底，避免“名称相似即同一公司”。
- 删除 Tushare `namechange` 历史名称修复及缓存，实体变化统一交给联网证据发现，市场 Provider 只验证当前证券目录。

## 非目标

- 不建立人工维护的公司别名表。
- 不使用搜索摘要直接生成金融数值结论。
- 不允许搜索失败时替换为同行业上市公司。
- 不在产品端展示原始网页、系统提示或模型隐藏推理。

## 架构

### 搜索 Provider

新增独立 `WebSearchClient` 契约。DeepSeek 实现使用 Anthropic Messages API 和服务端 `web_search` 工具，输出统一的搜索结果：查询词、标题、URL、摘要。Provider 负责协议转换和错误归一化，不负责金融实体判断。

### 搜索工具

新增只读 `web_search` 工具并注册到现有 Tool Registry。工具输入限制查询长度和最大结果数；输出只保留 URL、标题和有限长度摘要。调用仍经过 `ToolExecutionGateway`，因此继续适用目录冻结、RBAC、租户隔离、超时和敏感信息清理。

### 实体修复

`tool_agent` 收到 `stock.resolve_company` 的未命中 Observation 后执行一次受限 ReAct 修复：

1. 使用原始用户问题和失败公司名构造实体发现搜索，不使用市场目录相似候选。
2. 把搜索证据交给 LLM，要求输出结构化实体关系、候选上市主体、证券代码、来源 URL 和置信度。
3. 只接受允许的实体关系，并要求至少一个搜索来源。
4. 使用候选名称或代码再次调用原始 `stock.resolve_company` 工具。
5. 只有工具验证成功后，才更新 `$resolved_symbol` 和 `$resolved_name`。
6. 搜索、关系判断或权威复验任一步失败时，停止股票数据链路并返回“无法可靠确认上市主体”。

### 数据可信边界

- Web Search 是发现源，不是权威市场数据源。
- `stock.resolve_company` 的成功结果是证券身份进入后续工具的唯一入口。
- 搜索结果中的证券代码不能直接写入占位符。
- trace 记录搜索状态、结果数量、来源域名、修复关系和最终是否通过复验，不保存完整网页正文。

## 错误处理

- DeepSeek 搜索超时、限流和上游错误映射为稳定错误码，并标记是否可重试。
- 搜索无结果、缺少 URL、关系不明确或置信度不足均视为不可恢复，不继续猜测。
- 搜索结果包含多个可能主体时不自动选择；首版直接停止并要求用户澄清。
- 后续金融工具仍按现有 optional/required 字段策略处理。

## 测试策略

- DeepSeek 客户端测试覆盖 Anthropic Web Search 请求、结果解析、无结果和错误归一化。
- Tool 测试覆盖输入约束、输出截断和错误脱敏。
- Tool Agent 测试覆盖未命中后搜索、同一实体关系复验成功、同行候选拒绝、无来源拒绝及复验失败停止。
- 回归测试确认普通公司精确解析不触发搜索，RAG 和其他 MCP 工具链不受影响。

## 验收标准

- “分析一下长鑫存储”在证券目录精确未命中时会先联网发现，再通过市场数据工具验证上市主体和代码。
- 系统不会把晶合集成、兆易创新等同行业公司当作长鑫存储继续分析。
- 未联网、搜索失败或无法确认关系时返回可解释的实体识别失败，不生成替代公司的报告。
- 所有成功进入行情和财务工具的证券代码都来自 `stock.resolve_company` 的验证结果。
