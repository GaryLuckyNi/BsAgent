# 研究进展与搜索摘要展示

用户已选择研究进展流式展示，不额外开启 thinking。本次使用现有 SSE 事件展示目标、计划和实际工具状态；搜索完成后追加已有 answer，不增加模型调用或伪造逐字动画。

## 数据与交互

- 隐藏“查看任务明细”和“查看搜索范围”及其展开内容，查询方向由研究计划统一展示。
- Search API 若提供顶层字符串 answer，则传入既有 WebSearchResponse.answer，最多 20000 字符；缺失、空白或非字符串均为空，不以来源 snippet 代替。
- 公开完成事件仅携带成功 web_search 的非空 answer，复用已有脱敏，最多 4000 字符。兼容恢复取证的 search_result 包装。
- 活动分类优先读取当前任务实际执行工具；模型未预选工具时，客户端按 task_id 将开始事件从通用取证分组迁入实际工具分组，清除旧的进行中条目。
- 在 timeline 下方展示“搜索摘要”，按任务保存各搜索的 answer。一项搜索完成即可展示，不等待其他并行搜索或最终回答。无 answer 时不显示摘要区。
- 同一字段经 SSE、AG-UI、会话 metadata 和前端历史恢复传递。旧会话缺字段时保持兼容。
- 权限确认后的替代搜索逐项发布相同事件；恢复接口消费 custom 流并与中断前进度合并，合成正文沿用已有公开增量，不重复发送。恢复图结束后读取同线程最新检查点，保留后续中断，不因固定 checkpoint_id 读到恢复前状态。
- 折叠进度标题使用“研究进展”；摘要与 timeline 一起折叠，运行中保持展开。

## 验证与限制

使用离线 HTTP、事件和组件测试验证可选 answer、失败/空白过滤、并行增量、分组迁移、历史恢复和摘要位置；执行前端测试/构建及后端回归。现有 Search API 是非流式 HTTP，搜索摘要在该次请求完成时出现；本次不会新增供应商接口或开启 reasoning_content。
