# 研究记录搜索与删除

搜索框查询当前账号的真实会话内容，支持标题、摘要和历史正文命中，关键词按字面匹配，后端保持用户与租户隔离。前端短暂防抖并丢弃迟到结果；过滤列表不改变选中的会话及其标题。

每条记录的操作菜单仅包含删除。点击删除打开确认弹窗，展示会话标题，取消不发请求；确认期间禁止重复操作，失败保留记录并显示错误。删除当前记录后切换至其他记录，无记录则新建空白会话。

删除采用会话状态标记，保留执行审计及数据库关联，所有用户会话入口屏蔽已删除记录，并拒绝旧请求重放与继续提问。运行中的持久任务先走现有安全停止机制；无法安全停止的旧执行返回明确错误，保留会话，不伪装删除成功。删除过程遵守现有 execution、run、session 锁顺序，并校验活动任务未被并发替换。无需数据库迁移。

验收覆盖搜索归属、字面匹配、空结果、搜索时保留当前标题，菜单与确认、取消与失败、删除当前或其他记录、迟到响应不能恢复已删除记录，以及删除后的历史访问和请求重放。
