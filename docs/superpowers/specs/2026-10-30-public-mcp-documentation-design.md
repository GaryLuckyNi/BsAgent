# 公共第三方 MCP 字段说明异步补全

用户已确认：只处理明确配置为公共第三方的 MCP；目录发现时检查工具说明、入参和出参字段说明。缺口通过 Celery 异步搜索官方文档并用模型提取，研究请求不等待。未补全的工具仍可取数，未知语义不得猜测；只有影响核心结论时才说明限制。

原始工具契约和补充说明分开保存。服务端已有说明优先；模型提取结果只作语义上下文，不改变类型、必填、权限、风险和输出执行校验。保存来源 URL 与原文依据，未知单位或枚举留空。工具选择与合成使用同一 Run 固定的说明版本。

目录适配保留原始 outputSchema；补全资格由连接配置和官方文档域名声明，不通过名称或公网地址推测。公共 TuShare 配置提供该声明，通用 MCP 默认不启用。

持久化按连接身份、原始工具契约和文档域名生成任务键；有队列租约、运行租约与失败冷却，避免目录刷新重复派发和 Celery 重复投递。旧版本结果保存在旧键下，不会覆盖新契约。目录后台扫描限量派发，独立队列不占研究 worker。任务发布或补全失败不使目录构建和取数失败。

后台通过 Search 定位允许域名的文档，Fetch 取得正文；模型只依据正文提取字段说明。域名、字段身份、出处摘录与结果大小均校验。文档内容属于不可信资料，不具备执行指令或授予调用权限的能力。只将公开接口元数据入队，不传连接 URL、凭证、用户问题或数据查询结果。

新目录快照读取已完成的说明，既有 Run 保持原快照。Tool Agent 的函数契约带上说明，实际结果同时记录对应说明供合成使用。缓存更新不改变真实执行契约指纹。缺少说明时提供明确的未知状态，不自动触发失败或重规划。
