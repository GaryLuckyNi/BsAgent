# 会话操作弹层设计稿

用户已确认采用珊瑚红方案，现已应用到正式研究页面。原型位于 `frontend/design-prototypes/session-actions.html#coral`，仅用于设计比较，不连接真实接口，也不会打包进正式应用入口。

## 操作菜单

沿用研究工作区的深蓝、灰白与少量暖金色。菜单在每条研究记录的省略号下方展开，右边缘对齐触发按钮，下方保留约 6px 间距。菜单宽 160px、圆角 10px、细灰边与轻阴影；仅含一项“删除”，使用 16px 线性图标及低饱和红色文字，悬停背景为浅红，不额外增加菜单标题或说明。

点击外部或 Escape 关闭菜单；菜单展开时触发按钮保持可见。选择删除时关闭菜单，再进入确认框。

## 删除确认框

最大宽 420px，14px 圆角、24—26px 内边距和柔和阴影；背景采用低浓度深蓝遮罩，保留页面的上下文。标题为“删除这条研究？”，左侧是 36px 浅红底的垃圾桶图标，右侧为低强调关闭按钮。

正文展示研究名称并说明“及其聊天记录将从研究列表中移除”，次级文字说明“此操作无法在页面中撤销”。长名称自然换行。底部右对齐“取消”和“删除研究”，按钮高 36px、间隔 9px；取消为白底细边，删除为低饱和深红。

打开后默认聚焦取消；Escape、取消、关闭按钮均不删除。提交期间按钮禁用并显示“正在删除”，失败后保留弹窗和研究记录，错误紧贴操作区域。成功后关闭确认框并更新列表。

## 原型说明

左侧展示菜单与研究列表的关系，右侧展示确认框。原型支持展开菜单、取消、重新预览和模拟删除；模拟状态不修改任何真实会话。窄屏两组预览上下排列。

## 定稿配色与交互验证

确认按钮采用珊瑚红 `#bc5653`，悬停 `#a74745`；菜单删除项和图标使用 `#af4b49`，浅底为 `#fbefee`。深蓝正文和灰白界面沿用原设计。白色按钮文字对比度约 4.57:1。

已在正式页面验证菜单和确认框效果、默认聚焦取消、Escape 取消及焦点返回。删除成功后原按钮已移除时，焦点回到“新建研究”。提交期间禁止重复点击与关闭，失败时保留记录、展示错误并允许重试；由组件测试覆盖。真实用户的会话未用于删除验证，实际删除由隔离数据库测试覆盖。
