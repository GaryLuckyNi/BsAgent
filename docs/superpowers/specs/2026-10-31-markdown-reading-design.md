# Markdown 正文与来源预览设计

状态：已完成可交互设计预览，待用户确认视觉方案；尚未修改正式聊天页。

## 目标与现状

改善中文长文的阅读层级、加粗识别度与引用访问体验，保持现有深蓝、暖金、灰白的界面体系。正式页面仅显示回答本身，不增加预览页中的比较控制。

现有正文为 14px、400 字重，加粗为 600 且继承正文颜色。标题也使用 600 字重。编号引用由后端转换成普通 Markdown 链接，前端统一使用浅蓝色下划线。来源预览不能只改 CSS：虽然前端已有 EvidenceSource 类型与 HoverCard 原语，完成事件仍根据 cited_evidence_ids 构造占位资料，正文引用的标题、摘要与日期尚未完整贯通到实时消息和历史消息。

## 视觉方案

- 正文：用户提问与助手普通正文均为 16px、400 字重；助手正文为 1.8 行高，颜色 `#3e4857`。保持现有聊天内容宽度；后续整页字号协调见下文。
- 强调：700 字重、`#14243b`。中文系统字体缺少真实粗体字重时，正式接入需确认 scoped 字重合成，避免根级 font-synthesis:none 抑制强调效果；不全局替换字体或加载大体积外部字体。
- 标题：按用户最新要求，回答内各级标题统一 20px、700 字重；普通正文保持 16px，使用接近深蓝的正文强调色，通过语义和段前段后间距保持层次。
- 编号引用：约 20px 高的小号圆角徽标，11px 字号、600 字重，灰蓝文字、浅灰背景，无持续下划线；hover 使用暖金浅底和边框。普通文字链接仍使用独立链接样式，不把任意链接都识别为编号引用。
- 来源卡片：桌面最大宽度 368px，移动端不超过视口减 32px；白底、14px 圆角、细灰边、轻阴影。网站与日期在顶行，标题最多两行、摘要最多三行，底部为域名与打开原文入口。
- 来源网站图标使用真实 favicon：优先来源元数据已提供的图标地址，没有时尝试来源站点的 `/favicon.ico`；加载失败使用通用图标。保持原始图标颜色，不统一染色，不使用模型绘制网站 logo，也不引入第三方 favicon 聚合服务。图标固定尺寸避免加载时抖动，不额外触发搜索或模型调用。

## 整页字号协调（10 月 31 日追加）

用户要求优化正文调整后的整页比例。在既有配色、字体和布局下，统一主要文字层级：辅助信息 12px、界面文字 14px、阅读与输入 16px、回答标题 20px、页面标题桌面 24px／窄屏 20px。编号引用等紧凑标记保留独立字号。

侧栏标题、导航、作者、研究进展为 14px；侧栏摘要、时间、状态、输入提示为 12px。新建研究按钮从原先继承的 16px 调整为 14px，避免按钮与侧栏文字比例过大。输入文字与发送后的提问同为 16px；表格和代码块为 14px。来源入口、来源抽屉、历史搜索同步使用对应层级。

正文行高由 1.9 调为 1.8，标题上下间距由 1.6em／0.7em 调为 1.4em／0.6em；侧栏条目最小内容高度调为 72px，容纳 14px 标题与 12px 摘要。保持原有滚动、折叠、搜索、引用和来源入口时机，不改变业务行为。

## 原文 icon 边界

用户已明确：不要求每个标题都有 icon；正文或标题有则显示、没有则保持原样。icon 的颜色与样式遵从实际返回内容，不自动增加、替换、染色或删除。应用自身的按钮和状态图标继续沿用现有组件样式。本需求不修改模型输出以生成统一图标，也不将任意第三方 HTML/CSS 升级为可执行内容。

## 交互

- 悬停约 200ms 后打开，离开约 220ms 后关闭，允许指针从编号进入卡片并停留阅读。
- 卡片靠近当前编号，优先上方，空间不足时下方展示；限制水平边界，不被消息内容的 overflow 裁切。正式实现使用现有 Portal 能力。
- 编号点击保持打开原文的行为，地址校验及新标签页的安全属性保留。
- 键盘焦点可预览，Esc 关闭，可进入卡片的原文入口。触屏点击先展示卡片，再通过卡片入口访问原文。
- 卡片不增加正文高度、不推动阅读位置；遵从减少动态效果设置。

## 来源数据接入设计

正式实现应复用本次取证已有的来源，不因悬停新增搜索、网页抓取或模型总结。将来源编号、URL、标题、摘要、已知发布机构及发布日期传递到实时回答和持久化消息，前端按 URL 与编号关联。既有编号与文章地址保持一致，来源去重不能重排正文编号。

来源缺少日期或发布机构时省略对应元素，网站可按 URL 的 hostname 展示。只有 URL 的历史引用显示网站、地址与必要的内容未提供提示，不编造标题、摘要、日期和网站 logo。MCP 数据引用没有网页地址时仍走既有证据交互，不拼接假链接。

预览页中的网站、标题、日期和摘要均为明确标注的设计示例，不能用作生产证据；正式接入不得使用预览中的静态来源数据。
