# 工具执行与证据验收边界

用户已确认：普通工具执行负责可用性、参数、权限、预算与副作用，合成层根据 goal、计划和实际材料判断证据是否充分。不在执行前根据所需证据形态禁止取证。

source_requirement 保留为任务需求描述和旧计划兼容字段，不再决定普通搜索或恢复询问是否允许。数据源拔掉、只有 web_search 时，original_data 任务仍能检索实际资料，其是否满足需求由合成层判断。同一 run 中其他 MCP 调用失败也不构成普通搜索禁令，原失败记录与未决副作用不被覆盖或重放。

仅请求实际携带的 original_only、confirmation_required 阻止未经允许的普通搜索；经确认的恢复走原封存批次。固定 Skill 的绑定、恢复部署契约、回执状态、权限、调用身份、目录一致性和预算保护保持既有语义。不新建验收节点或模型调用。

Planner 提示词仅说明数据需求标签，不继续增加规避门禁的分类规则。已有 Router 来源约束继续传入 Planner。回归覆盖原始数据标签、缺失标签、历史 MCP 失败、用户明确来源限制，以及只有搜索工具时四个任务的完整派发与合成。
