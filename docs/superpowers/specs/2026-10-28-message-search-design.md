# 研究消息搜索与定位

## 用户需求与交互

将侧栏搜索输入框改为“搜索研究记录”按钮。点击后显示白底搜索弹窗，在弹窗内检索当前账号全部历史提问和回答，保持最近研究列表完整。参考用户提供的消息搜索样式，显示会话标题、消息时间、提问/回答类型和命中片段，关键词浅金色高亮；同一会话的多条消息分别列出。

弹窗宽度最多 760px，输入区固定、结果区独立滚动，窄屏保留两侧安全间距。输入后 250ms 防抖，查询变化立即清掉旧结果并取消旧请求。支持加载中、无结果、失败重试及加载更多。方向键选择，Enter 跳转，Escape/关闭按钮取消并恢复搜索按钮焦点。

选择条目后关闭弹窗，切换到对应会话并定位具体消息，使用轻底色标出目标，键盘焦点转到目标消息。搜索不发起模型调用。

## 接口与边界

新增 `GET /api/sessions/search?q=...&limit=30&offset=0`，返回 `items` 和 `next_offset`。每项包含 `session_id`、`message_id`、`title`、`snippet`、`role`、`sequence_no`、`created_at`。按消息时间及 ID 倒序分页，数据库先做归属、删除过滤和字面匹配，再读取当前页。空白查询返回空结果，关键词上限 200 字符，返回片段为纯文本，前端不注入 HTML。

普通会话仍只恢复最近 200 条。跳到更早消息时，沿现有历史分页向前补齐到目标，保留连续上下文以及当前流式内容和状态。取消、会话切换或新轮次使旧定位失效。目标已经删除或接口异常时显示定位失败提示。

## 初始化一致性

Workspace 定位 effect 等待 session 的 `isInitializing=false`。子组件 effect 会先于父组件初始化 effect 执行，不能依赖尚未赋值的默认已完成 Promise；等待恢复完成后再补历史，避免迟到的初始化结果覆盖定位目标。

## 验证

覆盖消息搜索权限隔离、软删除过滤、字面字符、历史正文、分页、摘要命中；前端覆盖防抖、迟到请求、键盘、重试、关闭焦点、跨会话首次挂载定位、200 条以前历史补齐及流式状态保留。浏览器使用真实历史只读验证搜索和跳转。
